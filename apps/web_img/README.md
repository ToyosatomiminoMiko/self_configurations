# web_img

局域网内看某个目录里的图片和文本。只读, 不写入、不删除、不改文件名。

## 跑起来

```bash
cd /mnt/IVSTINIANVS/__projects_python/web_img
uv venv .venv                                        # 首次执行
uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/python main.py                             # 不带任何参数
```

启动方式不带任何参数, 所有配置都在当前目录的 `conf.toml` 里:

```toml
dir = "."            # 要浏览的目录, 相对路径按 conf.toml 所在目录解析
host = "0.0.0.0"     # 监听所有网卡, 局域网其他机器才能访问
port = 8000
```

启动后会打印配置文件路径、根目录、本机地址和局域网地址。本机开 http://127.0.0.1:8000,
局域网其他机器开打印出来的那个 `http://<本机IP>:8000`。

配置缺失或写错(目录不存在、端口非法)会在启动阶段直接退出并打印原因。程序只读 `conf.toml`, 不会改写它。

## 用法

- 左栏点目录进入, 面包屑可以回上层。
- 点图片在右栏放大; 翻页: 「上一张 / 下一张」按钮、键盘 ←/→、滚轮、点图片本身(下一张)。
- 到第一张/最后一张就停住, 不循环。
- 点文本文件右栏显示内容, 超过 1 MB 只显示前 1 MB。
- 其他类型文件点击在新标签页打开原文件(相当于下载)。
- 地址栏带 `?dir=子目录`, 刷新和分享链接都能回到同一目录。

## 接口

| 路径 | 作用 |
| --- | --- |
| `GET /` | 页面 |
| `GET /api/list?path=` | 目录列表 + 面包屑 |
| `GET /api/text?path=` | 文本内容(截断 1 MB) |
| `GET /media/{path}` | 原始文件字节 |

## 已知边界

- 没有鉴权、没有 HTTPS, 仅限可信局域网使用。
- 页面是单文件、无构建步骤; 修改 `templates/index.html` 后刷新浏览器即可。
- 没有缩略图缓存, 图片很多的大目录会给硬盘和带宽一些压力(靠 `loading=lazy` 缓解)。
